# Edudata Flujo

MVP local para visualizar el avance mensual de las bases de datos de Edudata.

## Ejecutar

Abra `dist/index.html` en un navegador. La aplicación no requiere instalación ni servicios externos.

Los cambios de demostración se guardan únicamente en el almacenamiento local del navegador. Para restaurar los datos iniciales use el botón **Restablecer demo**.
